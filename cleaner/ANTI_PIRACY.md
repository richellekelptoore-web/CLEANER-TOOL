Memory Clearer includes multiple safeguards:

## WHAT CONSTITUTES PIRACY

### ❌ NOT ALLOWED

1. **Unauthorized Redistribution**
   - Distributing without .official_marker
   - Hosting on personal server without attribution
   - Modifying and not documenting changes

2. **Copyright Removal**
   - Deleting COPYRIGHT_NOTICE.txt
   - Removing copyright from code comments
   - Removing license file
   - Removing author attributions

3. **Malware Distribution**
   - Adding malware to "leaked" versions
   - Creating trojanized copies
   - Distributing as "cracked" versions
   - Packaging with ransomware

4. **False Representation**
   - Claiming you wrote the software
   - Removing original authorship
   - Using false "official" markers
   - Creating fake "official" websites

5. **License Violation**
   - Redistributing without MIT License
   - Using proprietary/commercial license
   - Claiming proprietary rights
   - Sublicensing under different terms

### ✅ ALLOWED

1. **Proper Redistribution**
   - Including MIT License file
   - Including COPYRIGHT_NOTICE.txt
   - Documenting all changes
   - Providing attribution
   - Keeping .official_marker (if official copy)

2. **Modification**
   - Modifying source code
   - Creating derivative works
   - Building on the software
   - Using for commercial purposes

3. **Attribution**
   - Stating: "Based on Memory Clearer"
   - Linking to original project
   - Listing modifications
   - Crediting original authors

4. **Sublicensing**
   - Releasing modified version under MIT
   - Using in projects with compatible licenses
   - Creating commercial products
   - Building proprietary tools on top
