# Changelog

All notable changes to Memory Clearer are documented in this file.

## [2.0] - 2024-01-15

### Added
- Real-time memory monitoring dashboard
- Configurable cleanup schedules
- Detailed activity logging
- Deep clean feature for thorough system cleanup
- Command-line interface (CLI) support
- Auto-cleanup at configurable intervals
- System status reporting

### Changed
- Improved memory detection accuracy
- Enhanced GUI responsiveness
- Optimized cleanup algorithms
- Updated requirements for better compatibility

### Fixed
- Memory calculation errors on some systems
- Daemon process stability issues
- Log file rotation problems

## [1.0] - 2023-06-01

### Added
- Initial release
- Basic memory cleanup functionality
- Simple GUI interface
- Configuration file support
- Logging system
